# S3 Bucket & Key Conventions (Track 1)

## Buckets
| Bucket | Purpose | Lifecycle |
|---|---|---|
| `ecolens-raw` | Original user uploads | Versioning on |
| `ecolens-thumbs` | Generated thumbnails | Move to IA after 30 days |
| `ecolens-frames` | Extracted video frames (1 fps) | none |
| `ecolens-query-tmp` | Transient uploads for "query by file" | Expire after 1 day |

All buckets: Block Public Access ON. Region: `us-east-1`.

## Key naming
- Raw:     `uploads/{user_sub}/{file_id}.{ext}`
- Thumb:   `thumbs/{user_sub}/{file_id}.jpg`
- Frames:  `frames/{file_id}/{second:04d}.jpg`
- Query:   `query/{request_id}.{ext}`

`user_sub` = Cognito user ID (sub claim from JWT, supplied by Track 2).
`file_id` = UUID v4 generated by upload-handler Lambda.
